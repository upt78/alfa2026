# REST API

Базовый URL при Docker-запуске: `http://localhost:8001`. Формат — JSON. Интерактивная документация: `/docs`; машинная схема: [`openapi.json`](openapi.json).

| Метод и путь | Назначение | Основные ответы |
|---|---|---|
| `GET /health` | Проверка приложения и соединения с БД | `200` |
| `GET /products` | Каталог кредитных продуктов | `200` |
| `POST /recommendations` | До 3 персональных предложений с `match_score` и `reason` | `200`, `422` |
| `POST /applications` | Создание заявки и компании/обновление показателей | `201`, `404`, `422` |
| `GET /applications?inn=...` | Все сохранённые заявки компании, новые первыми | `200`, `422` |
| `GET /applications/{id}` | Заявка, решение и полная история статусов | `200`, `404` |
| `POST /applications/{id}/clarify` | Ответ на уточнение; переход на `external_check` | `200`, `404`, `409`, `422` |
| `POST /applications/{id}/sign` | Локальное подписание; переход в `issued` | `200`, `404`, `409` |

## Создание заявки

```json
{
  "company_name": "ООО Ромашка",
  "inn": "7701234567",
  "revenue": 24000000,
  "age_years": 7,
  "product_id": 1,
  "amount": 2000000,
  "term_months": 24,
  "purpose": "Пополнение оборотных средств"
}
```

ИНН содержит 10 цифр для ООО или 12 для ИП. `revenue` и `amount` передаются в рублях, срок — в месяцах. Предварительная проверка лимитов намеренно выполняется в конвейере: нарушения могут привести к `clarification`.

## Уточнение

`POST /applications/{id}/clarify`:

```json
{"comment": "Подтверждаю выручку за последние 12 месяцев"}
```

## Ответ заявки

Помимо параметров содержит `status`, `score`, `offer_rate`, `decision_comment`, вложенные `company`, `product` и массив `history`. Времена сериализуются в ISO 8601. Идентификаторы заявок и продуктов числовые.

Готовые запросы: [`collection.http`](collection.http).
